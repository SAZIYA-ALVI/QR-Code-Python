# QR Code Generator using Python

This project demonstrates how to **generate QR Codes using Python**.

## 📌 About the Project

A QR Code (Quick Response Code) is a two-dimensional barcode that can store information such as:

* Text
* URLs
* Contact information
* Other data

This project uses Python to generate QR Codes from user-provided information.

## 🛠️ Technologies Used

* Python
* QR Code Library
* Jupyter Notebook / Python IDE

## 📂 Project Files

* `qr_code.py` — Python program for generating a QR Code
* `qr_code12.py` — Another QR Code generation example
* `Qr Code Genrate.png` — Generated QR Code output
* `qr code Genrate 12.png` — Generated QR Code output

## ⚙️ How It Works

```text
Input Data
    ↓
Python Program
    ↓
QR Code Generation
    ↓
PNG Image
```

## 🚀 How to Run

### 1. Install the required library

```bash
pip install qrcode[pil]
```

### 2. Run the Python file

```bash
python qr_code.py
```

### 3. Enter or provide the required information.

The program generates a QR Code image containing the given data.
